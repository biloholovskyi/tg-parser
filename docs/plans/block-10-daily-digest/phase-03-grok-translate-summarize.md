# Phase 03 — Перевод и саммари через Grok

Статус: done

Требуемые правила: `.claude/rules/runtime-resources.md`, `.claude/rules/patterns.md`, `.claude/rules/testing.md`

## Цель

Собранные посты переводятся на русский и сворачиваются в сухое саммари по темам, в котором гарантированно учтён каждый пост.

## Заметки по реализации

- Разделы «Перевод» и «Саммари и полнота» в [design.md](design.md) — источник требований к промптам и проверке.
- В начале фазы сверить через context7 или документацию xAI: базовый URL, имя модели по умолчанию, формат ответа по JSON-схеме.
- Логика полноты и нарезки пишется чистыми функциями, чтобы тестироваться без HTTP.
- Промпты — константы в `src/digest/grok/prompts.ts`, на английском с требованием отвечать по-русски.

## Объём

- `src/digest/grok/grok.client.ts` — `completeJson(system, user, schema)`: `fetch` с `AbortSignal.timeout(GROK_CALL_TIMEOUT_MS)`, до GROK_MAX_RETRIES повторов только на 429, 5xx и таймаут, разбор и проверка формы JSON; ошибки без ключа API и без текста постов.
- `src/digest/grok/prompts.ts` — промпт перевода и промпт саммари с правилами: без оценок и выводов, пост — утверждение источника, объединение одной темы из разных каналов, `viewpoints` с каналом при противоположных версиях, каждый `ref` хотя бы в одной теме, тезис — одно короткое предложение.
- `src/digest/translation.service.ts` — пачки по GROK_TRANSLATE_BATCH_CHARS, обрезка до DIGEST_POST_MAX_CHARS, дозапрос пропущенных `ref`, оригинал как резерв с флагом.
- `src/digest/utils/coverage.ts` — `findMissingRefs`, `dropUnknownRefs`.
- `src/digest/summary.service.ts` — первичный вызов, до SUMMARY_COVERAGE_RETRIES дозапросов для пропущенных, резервные блоки из первых DIGEST_FALLBACK_THESIS_CHARS символов перевода; результат `DigestTopic[]` и флаги резерва.
- `src/digest/constants.ts` — константы Grok, перевода и саммари.

## Команды проверки

- `rtk npm.cmd run lint`
- `rtk npm.cmd run build`
- `rtk npm.cmd test`

## Критерии приёмки

- Для любого ответа модели, включая пустой и полностью выдуманный, множество `ref` в итоговых темах равно множеству `ref` входа с текстом (свойство проверено тестом на нескольких сценариях).
- Таймер таймаута очищается во всех ветках (тест на фальшивых таймерах).
- Ни одна строка лога не содержит текст поста.

## Доказательства

- Документация xAI сверена через context7: `https://api.x.ai/v1/chat/completions`, `response_format` типа `json_schema` со `strict`, модель по умолчанию `grok-4.6`.
- `rtk npm.cmd run lint`, `rtk npm.cmd run build` — без ошибок.
- `rtk npm.cmd test` — 43 набора, 838 тестов, все зелёные; тестов этой фазы 126.
- Свойство полноты проверено на 7 сценариях в `summary.service.spec.ts`: объединение `ref` в темах равно множеству `ref` постов с текстом.
- Очистка таймера проверена во всех ветках (`jest.getTimerCount()` и слежка за `clearTimeout`); проверка на копии кода без `clearTimeout` роняет 11 тестов.
- Логи и тексты ошибок не содержат текста постов и ключа API (проверено тестами).
