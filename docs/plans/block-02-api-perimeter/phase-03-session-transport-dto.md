# Phase 03 — Транспорт строки сессии и DTO

Статус: done

Требуемые правила: `.claude/rules/api-security.md`, `.claude/rules/api-contracts.md`, `.claude/rules/telegram.md`, `.claude/rules/testing.md`

## Цель

Строка сессии передаётся заголовком, а форма каждого запроса описана DTO с исполняемой проверкой.

## Заметки по реализации

DTO авторизации переписывается с нуля: номер телефона, код и пароль получают декораторы формата и длины. Ручной разбор `hoursBack` в контроллере заменяется DTO запроса. Замена пробелов на плюс в строке сессии исчезает вместе с передачей через URL.

## Объём

- Строка сессии принимается заголовком SESSION_HEADER на маршрутах `me` и постов.
- DTO авторизации проверяет формат номера телефона, формат кода и наличие пароля только на шаге 2FA.
- DTO запроса постов проверяет имя канала и диапазон `hoursBack`, значения вынесены константами.
- Неиспользуемые DTO удалены.
- Контроллер остаётся тонким: разбор и проверка уходят в DTO, вызов — в сервис.
- Ответы об ошибках не раскрывают существование аккаунта, сессии или канала сверх необходимого.

- Некорректный номер телефона отклоняется до обращения к Telegram.
- `hoursBack` вне диапазона отклоняется с понятным сообщением.
- E2E-сценарий на все маршруты проходит с подменённым сервисом.

## Результат

- `SESSION_HEADER` вынесен в `src/shared/constants/http.constants.ts` и переиспользован в `cors.config.ts`; строка сессии читается хелпером `readSessionHeader` и параметр-декоратором `@SessionString()`.
- Маршруты `me` и постов берут учётные данные из заголовка; `sessionString` в query отклоняется глобальной валидацией с 400, замена пробелов на плюс удалена вместе с передачей через URL.
- `dto/messages.dto.ts` переписан: `ChannelPostsParamsDto` проверяет имя канала по шаблону из констант длины, `GetPostsQueryDto` — целочисленный `hoursBack` в диапазоне; мёртвый `GetPostsDto` удалён.
- `dto/auth.dto.ts` получил `PasswordRequiresPhoneCodeConstraint`: пароль принимается только вместе с кодом, то есть на шаге 2FA.
- Контроллер остался тонким: мёртвая проверка `phoneNumber` убрана, разбор и проверка ушли в DTO.
- Артефакты `docs/testing/` обновлены: модель авторизации, случаи периметра P1-P7, V8-V9, папка `perimeter` и переменная `apiKey` в коллекции Postman.
- Проверки: lint чисто, build успешно, `rtk npm test` — 18 наборов и 199 тестов, `rtk npm run test:e2e` — 3 набора и 36 тестов, всё зелёное.
