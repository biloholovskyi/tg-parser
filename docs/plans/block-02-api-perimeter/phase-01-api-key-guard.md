# Phase 01 — Ключ доступа и гвард

Статус: todo

Требуемые правила: `.claude/rules/api-security.md`, `.claude/rules/architecture.md`, `.claude/rules/testing.md`

## Цель

Каждый маршрут, кроме health-проверки, требует действительный ключ вызывающей стороны.

## Заметки по реализации

Гвард и загрузчик ключей пишутся с нуля. Health-маршрут помечается как публичный через метаданные, а не исключением по строке пути.

## Объём

- Загрузчик ключей доступа в `src/config/` читает значения только из окружения.
- Гвард сверяет заголовок AUTH_HEADER со списком ключей и отдаёт 401 без подробностей о причине.
- Отсутствие настроенных ключей означает отказ в доступе, а не открытый режим.
- Health-маршрут помечен публичным и работает без ключа.
- Гвард зарегистрирован на уровне модуля Telegram.

## Чеклист

- [ ] Загрузчик ключей с юнит-тестом на отсутствующее и множественное значение
- [ ] Гвард с тестами: верный ключ, неверный ключ, отсутствующий заголовок, публичный маршрут
- [ ] Регистрация гварда в `src/telegram/telegram.module.ts`
- [ ] Переменная окружения описана в `CLAUDE.md`
- [ ] Ключи не попадают в логи и в сообщения ошибок
- [ ] Тесты фазы написаны агентом `test-writer`

## Команды проверки

- `rtk npm run lint`
- `rtk npm run build`
- `rtk npm test`

## Критерии приёмки

- Запрос без заголовка к `auth`, `me` и маршруту постов получает 401.
- Health-маршрут отвечает 200 без заголовка.
- Ответ 401 не сообщает, существует ли такой ключ.
