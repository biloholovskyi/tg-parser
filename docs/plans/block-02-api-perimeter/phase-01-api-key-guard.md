# Phase 01 — Ключ доступа и гвард

Статус: done

Требуемые правила: `.claude/rules/api-security.md`, `.claude/rules/architecture.md`, `.claude/rules/testing.md`

## Цель

Каждый маршрут, кроме health-проверки, требует действительный ключ вызывающей стороны.

## Заметки по реализации

Гвард и загрузчик ключей пишутся с нуля. Health-маршрут помечается как публичный через метаданные, а не исключением по строке пути.

## Объём

- Загрузчик ключей доступа в `src/config/` читает значения только из окружения.
- Гвард сверяет заголовок AUTH_HEADER со списком ключей и отдаёт 401 без подробностей о причине.
- Отсутствие настроенных ключей означает отказ в доступе, а не открытый режим.
- Health-маршрут помечен публичным и работает без ключа.
- Гвард зарегистрирован на уровне модуля Telegram.

- [x] Гвард с тестами: верный ключ, неверный ключ, отсутствующий заголовок, публичный маршрут

- [x] Переменная окружения описана в `CLAUDE.md`

## Команды проверки

- `rtk npm run lint`
- `rtk npm run build`
- `rtk npm test`

## Критерии приёмки

- Запрос без заголовка к `auth`, `me` и маршруту постов получает 401.
- Health-маршрут отвечает 200 без заголовка.
- Ответ 401 не сообщает, существует ли такой ключ.

## Результат

- `src/config/api-keys.config.ts` — загрузчик `API_KEYS`: разбор списка, обрезка пробелов, схлопывание дублей, предупреждение при пустом значении. Значения ключей в лог не попадают.
- `src/shared/guards/api-key.guard.ts` — сверка заголовка `x-api-key` со списком ключей в постоянном времени, единый `UNAUTHORIZED_MESSAGE` на все причины отказа, пустой список ключей означает отказ.
- `src/shared/decorators/public-route.decorator.ts` — метка публичного маршрута; сравнения по строке пути нет.
- `src/telegram/telegram.module.ts` — гвард зарегистрирован через `APP_GUARD`; `@PublicRoute()` стоит только на health.
- `API_KEY_HEADER` вынесен в `src/shared/constants/http.constants.ts` и переиспользован в `cors.config.ts`.
- Тесты написаны агентом `test-writer`: 3 новых спека (28 кейсов), E2E обновлены под гвард.
- Проверки: `rtk npm run lint` — чисто, `rtk npm run build` — успешно, `rtk npm test` — 10 наборов, 111 тестов, все зелёные.
- Остаточное: при незаданном `API_KEYS` предупреждение пишется на каждый запрос; объём логов ограничит рейт-лимит Phase 02.
