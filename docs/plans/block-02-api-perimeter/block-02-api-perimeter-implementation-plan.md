# Блок 02 — Периметр доступа

## Миссия

- Ни один эндпоинт, кроме health-проверки, не выполняется без ключа вызывающей стороны.
- Стоимость запроса к Telegram ограничена рейт-лимитом, а строка сессии не появляется в URL.

## Профиль задачи

`feature` — 3 сигнала: новая возможность (аутентификация вызывающей стороны), изменение контракта запроса, затронут весь набор маршрутов.

## Тир сложности

`standard` — периметр REST и транспорт учётных данных входят в HIGH_RISK_SURFACE.

## Целевая версия

Уточняется пользователем перед стартом работ.

## Высокорисковая поверхность

Да — аутентификация, транспорт учётных данных, стоимость обращений к Telegram. Риски: [risks.md](risks.md).
