# Блок 06 — Тесты

## Миссия

- Существующая функциональность закрыта тестами до целевого уровня покрытия.
- Каждый маршрут, каждый публичный метод сервиса и каждая ветка отображения ошибки имеют проверку.

## Профиль задачи

`feature` по форме (новые файлы), но без изменения поведения продукта: продакшен-код этим планом не правится.

## Тир сложности

`small` — один модуль, модель сессий не меняется, контракт не меняется, высокорисковая поверхность не затрагивается. Объём правок велик, но это единственный сигнал `standard`, поэтому тир остаётся `small`: без отдельного отчёта и без `reflect.md`.

## Границы

- План не правит продакшен-код. Обнаруженное расхождение оформляется находкой и передаётся в соответствующий блок, а не чинится здесь.
- План покрывает поведение, существующее на момент старта. Если параллельно закрывается блок 01, 02 или 03-05, тесты на изменённое поведение пишутся внутри тех фаз, а сюда попадает остаток.
