# Блок 06 — Research

## Затрагиваемые файлы

- Новые `*.spec.ts` рядом с исходниками в `src/`
- Новые `test/*.e2e-spec.ts`
- `test/jest-e2e.json` — конфигурация E2E
- `package.json` — раздел Jest

## Наблюдаемое состояние

- Один спек-файл: `src/config/telegram.config.spec.ts`, три проверки.
- Покрытие по строкам: 2.39 процента суммарно; `telegram.service.ts`, `telegram.controller.ts` и DTO — ноль.
- Каталог `test/` содержит только конфигурацию, ни одного E2E-сценария.
- Конфигурация Jest объявлена в `package.json` с корнем `src`, поэтому E2E запускаются отдельной конфигурацией.

## Ограничения

- Реальное соединение MTProto в тестах запрещено; клиент GramJS подменяется.
- В фикстурах используются только очевидные подделки: ни настоящей строки сессии, ни настоящего номера, ни настоящих идентификаторов приложения.
- E2E поднимают приложение с подменённым `TelegramService`.
- Тесты пишет агент `test-writer`; он не правит продакшен-код ради зелёного прогона.

## Целевые значения

- Покрытие юнит-тестами не ниже 0.8
- Покрытие интеграционными и E2E не ниже 0.7
