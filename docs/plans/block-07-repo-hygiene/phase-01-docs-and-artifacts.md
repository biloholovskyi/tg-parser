# Phase 01 — Чистка документов и артефактов

Статус: todo

Требуемые правила: `.claude/rules/tooling.md`, `.claude/rules/commit-message-and-crosslinks.md`

## Цель

В корне репозитория остаются только действующие документы, артефакты данных не хранятся в гите.

## Заметки по реализации

Каждый документ получает одно из трёх решений: остаётся в корне, переезжает в `docs/`, удаляется. Решение принимается по тому, описывает ли документ действующее состояние.

## Объём

- В корне остаются `README.md`, `CHANGELOG.md`, документ по развёртыванию и `CLAUDE.md`.
- Документы о разовых инцидентах и о состоянии генерации удалены.
- Документы, сохраняющие ценность, перенесены в `docs/` и связаны из `README.md`.
- `README.md` описывает действующий набор эндпоинтов, переменных окружения и команд.
- `posts_data/` исключён из отслеживания и добавлен в `.gitignore`.
- Судьба `.cursor/` решена и зафиксирована.
- Ссылки между документами проверены и не ведут на удалённые файлы.

## Чеклист

- [ ] Решение по каждому документу в корне принято и применено
- [ ] `README.md` соответствует действующему коду
- [ ] `posts_data/` не отслеживается и игнорируется
- [ ] `.cursor/` оставлен или удалён по решению
- [ ] Битых ссылок между документами нет

## Команды проверки

- `rtk git status`
- `rtk rg --files`

## Критерии приёмки

- В корне не больше пяти файлов markdown.
- `rtk git status` не показывает файлы выгруженных постов.
- Ни одна ссылка в оставшихся документах не ведёт на удалённый файл.
