# Phase 02 — Версия и журнал изменений

Статус: done

Требуемые правила: `.claude/rules/versioning-changelog.md`, `.claude/rules/drift-audit.md`

## Цель

Версия пакета, имя ветки и журнал изменений описывают одно состояние.

## Заметки по реализации

Записи за пропущенные версии восстанавливаются по истории коммитов. Формулировки отражают результат для пользователя, а не перечень правок.

## Объём

- `CHANGELOG.md` содержит записи за версии между последней зафиксированной и целевой.
- Каждая запись оформлена заголовком с версией и датой в формате дня, месяца и года.
- Версия в `package.json` равна целевой.
- Имя ветки соответствует шаблону `r-{версия}`; переключение или создание ветки предлагается пользователю и выполняется только с его согласия.

## Чеклист

- [x] Пропущенные записи журнала восстановлены
- [x] Версия в `package.json` равна целевой
- [x] Соответствие имени ветки проверено, изменение только по согласию
- [x] Формат заголовков записей единообразен

## Команды проверки

- `rtk git log --oneline`
- `rtk git branch`

## Критерии приёмки

- Три значения — версия пакета, имя ветки и верхняя запись журнала — согласованы.
- Ни одна запись журнала не ссылается на несуществующую работу.
