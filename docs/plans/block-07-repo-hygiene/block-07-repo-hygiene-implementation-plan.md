# Блок 07 — Гигиена репозитория

## Миссия

- В корне репозитория лежит только то, что читают: README, CHANGELOG, инструкция по развёртыванию и `CLAUDE.md`.
- Версия в `package.json`, ветка и `CHANGELOG.md` описывают одно и то же состояние.

## Профиль задачи

`bugfix` — 2 сигнала: расхождение версии и журнала изменений, отсутствие изменений в поведении продукта.

## Тир сложности

`small` — продакшен-код не затрагивается, контракт не меняется, высокорисковая поверхность не затрагивается.

## Целевая версия

Уточняется пользователем перед стартом работ. Этот блок приводит журнал изменений в соответствие с ней.

## Высокорисковая поверхность

Нет. `risks.md` не требуется.
