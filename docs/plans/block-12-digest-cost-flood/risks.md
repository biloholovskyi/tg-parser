# Риски — блок 12

## Затронутая высокорисковая поверхность

- Новое хранимое состояние: записи `tg:peer:*` в Redis.
- Жизненный цикл запроса к Telegram: обращение к каналу по сохранённым `channelId` и `accessHash`.

## Режимы отказа

| Отказ | Последствие | Сколько стоит неделя в проде | Защита |
|-------|-------------|------------------------------|--------|
| Сохранённый `accessHash` устарел (канал пересоздан, имя передано другому каналу) | Чтение не того канала или ошибка | Неверные посты в дайджесте одного канала | Ошибки `CHANNEL_PEER_STALE_ERRORS` и `CHANNEL_UNAVAILABLE_ERRORS` удаляют запись и повторяют поиск; срок жизни `CHANNEL_PEER_TTL_S` |
| Имя канала передано другому каналу без ошибки Telegram | До `CHANNEL_PEER_TTL_S` читается старый канал | Пропуск нового канала до 30 дней | Принятый риск, описан в ADR; сброс — удалить ключи `tg:peer:*` |
| Redis недоступен | Кэш пуст, каналы ищутся по имени | Поведение версии 1.5.1 | Ошибка кэша не срывает запрос |
| Ключ раскрывает связь аккаунта и каналов | Владелец Redis видит хэш сессии и имена каналов | Нет денежной стоимости | В ключе только SHA-256 сессии; без сессии `accessHash` бесполезен |
| Ожидание лимита держит запуск до часа | Ручной запуск получает 409, дайджест приходит позже | Нет | Пределы `DIGEST_FLOOD_WAIT_MAX_S` и `DIGEST_FLOOD_WAIT_TOTAL_MAX_S`, алерт о каждом ожидании |
| Пауза не отменяется при остановке | Остановка процесса задерживается | Задержка деплоя | Отменяемая пауза, `unref()`, тест на отмену |
| Дешёвая модель переводит плохо | Плохие тезисы резервных блоков или плохой перевод в режиме `on` | Хуже читаемость | `GROK_TRANSLATION_MODEL` меняется без деплоя кода |
| Основная модель хуже группирует по оригиналам | Слабее тезисы | Хуже читаемость | `DIGEST_TRANSLATION=on` включает отдельный перевод перед сводкой |
| Дешёвая модель не поддерживает `json_schema` | Перевод не выполняется | Резервные тезисы без перевода | Проверка в Phase 03 по docs.x.ai и на смоук-запуске |

## Секреты

- `sessionString` не попадает ни в ключ, ни в значение, ни в лог: в ключе только `hashSecret`.
- `accessHash` не логируется и не попадает в алерты.

## Откат

1. Быстрый, без кода: `DIGEST_TRANSLATION=on`, `GROK_TRANSLATION_MODEL=grok-4.6`, `GROK_TRANSLATION_REASONING_EFFORT=low` — отдельный перевод основной моделью.
2. Кэш каналов: удалить ключи `tg:peer:*` в Redis (сервис снова найдёт каналы по имени).
3. Полный: задеплоить коммит версии 1.5.1. Записи `tg:peer:*` версия 1.5.1 не читает; они истекут через `CHANNEL_PEER_TTL_S`.
