# Блок 12 — Дешёвый дайджест и устойчивость к лимитам Telegram

## Миссия

- Часть А, стоимость: сводку строит основная модель прямо по оригиналам постов, отдельный перевод выключен по умолчанию и включается переменной окружения; перевод, где он нужен, делает отдельная дешёвая модель, которую можно заменить через env.
- Часть Б, лимиты: ограничение частоты запросов Telegram во время сбора постов не срывает дайджест — каналы не ищутся по имени каждый вечер, а короткое ожидание выдерживается и сбор продолжается с того же канала.

## Профиль задачи

`feature` — 3 сигнала feature (новая возможность, три модуля, архитектурный выбор хранения), 1 сигнал bugfix (воспроизводимый срыв дайджеста 12.10.2026).

## Тир сложности

`standard` — меняется то, что сервис хранит (кэш каналов в Redis), затронуты модули `telegram`, `digest`, `config`, новые переменные окружения.

## Новые переменные окружения

| Переменная | Значения | По умолчанию |
|------------|----------|--------------|
| `DIGEST_TRANSLATION` | `off` — сводка по оригиналам; `on` — отдельный перевод перед сводкой | `off` |
| `GROK_TRANSLATION_MODEL` | любая модель xAI | `grok-4.20-0309-non-reasoning` |
| `GROK_TRANSLATION_REASONING_EFFORT` | как у `GROK_REASONING_EFFORT` | `off` |

Перевод всех постов основной моделью: `DIGEST_TRANSLATION=on`, `GROK_TRANSLATION_MODEL=grok-4.6`, `GROK_TRANSLATION_REASONING_EFFORT=low`.
