# Блоки 08-09 — Research

## Затрагиваемые файлы

- `src/telegram/telegram.service.ts` — 544 строки, четыре области ответственности в одном классе
- `src/telegram/interfaces/message.interface.ts` и `src/telegram/dto/` — типы
- `tsconfig.json` — режим компилятора
- Все спек-файлы модуля — при перемещении кода

## Наблюдаемое состояние

- Метод авторизации занимает около 210 строк при пределе в 20 и пороге рефакторинга в 30.
- В одном классе соседствуют: многошаговая авторизация, кэш клиентов, файловое хранилище, обход сообщений, преобразование сообщения в ответ.
- Строка сессии и номер телефона с хешем кода сохраняются в `data/sessions.json` и `data/auth-states.json`.
- Файловая система развёртывания эфемерна: содержимое `data/` исчезает при каждом выкате.
- `tsconfig.json` объявляет `strictNullChecks: false`, `noImplicitAny: false`, `strictBindCallApply: false`.
- Объявлены и не используются `StartAuthDto`, `GetPostsDto`, поле `url` в описании вложения.
- Числовые литералы таймаутов, интервалов и лимитов встречаются в коде без именованных констант.

## Ограничения

- Хранилище сессий — открытая развилка, зафиксированная в `.claude/rules/telegram.md`. Правило запрещает расширять файловое хранилище и запрещает переписывать правило под код без решения пользователя.
- Правила требуют: один класс не длиннее 200 строк, функция не длиннее 20, вложенность не глубже 3.
- Перемещение кода без тестов небезопасно, поэтому блок идёт после того, как поведение закрыто проверками.

## Варианты хранилища (вход для ADR)

| Вариант | Что даёт | Чем платим |
|---------|----------|------------|
| Только память | Секреты не покидают процесс, правило соблюдено | Перезапуск требует повторной передачи строки сессии |
| Внешнее хранилище с шифрованием | Сессии переживают перезапуск, возможен рост числа инстансов | Новая зависимость, управление ключом шифрования, расходы |
| Оставить файлы | Изменений не требуется | Учётные данные на диске, пользы нет из-за эфемерной файловой системы |

## Открытые вопросы

- Нужен ли маршрут завершения сессии по требованию.
