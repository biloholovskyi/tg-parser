# Phase 02 — Распил сервиса

Статус: done

Требуемые правила: `.claude/rules/architecture.md`, `.claude/rules/patterns.md`, `.claude/rules/telegram.md`, `.claude/rules/testing.md`

## Цель

Модуль Telegram состоит из единиц, каждая из которых отвечает за одно, и укладывается в пределы из правил.

## Заметки по реализации

Целевая структура описана в [design.md](design.md). Перемещение выполняется при зелёных тестах: сначала проверки, затем перенос, затем повторный прогон. Поведение при переносе не меняется — изменения поведения принадлежат другим блокам.

## Объём

- Единицы из таблицы в `design.md` созданы, ответственность распределена по ней.
- Клиент GramJS создаётся единственной фабрикой с явными опциями.
- Владение жизненным циклом клиента принадлежит только хранилищу сессий.
- Преобразование сообщения вынесено в функцию без состояния.
- Числовые пределы модуля собраны в `constants.ts` с единицами измерения в именах.
- Неиспользуемые DTO и поля удалены.
- Контроллер не импортирует ничего из пакета `telegram`.
- Пределы соблюдены: класс не длиннее 200 строк, функция не длиннее 20, вложенность не глубже 3.

- Поиск по проекту не находит импорта пакета `telegram` вне `src/telegram/`.
