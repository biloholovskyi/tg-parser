# Phase 03 — Строгость TypeScript

Статус: done

Требуемые правила: `.claude/rules/typescript.md`, `.claude/rules/patterns.md`, `.claude/rules/testing.md`

## Цель

Компилятор проверяет обязательность типов и обработку отсутствующих значений во всём проекте.

## Заметки по реализации

Строгость включается после того, как файлы перестали перемещаться. Результаты MTProto сужаются на границе сервиса описанными типами, а не приводятся к свободному типу ради прохождения сборки.

## Объём

- `strictNullChecks` и `noImplicitAny` включены.
- Каждое место, где значение может отсутствовать, обрабатывает это явно.
- Формы ответов MTProto сужены описанными типами на границе сервиса.
- Свободный тип не используется как способ заглушить компилятор; каждое оставшееся применение обосновано комментарием с причиной.
- Правило `.claude/rules/typescript.md` описывает включённый режим.
