# Блоки 03-05 — Сервис Telegram

Объединяет три блока, которые делят один файл `src/telegram/telegram.service.ts`: жизненный цикл клиентов, выборка постов с кодами ответов, логирование.

## Миссия

- Каждый созданный клиент Telegram имеет потолок, срок жизни и путь освобождения.
- Ответ сервиса честен: обрезанная выборка помечена, отказ Telegram отражён кодом состояния.
- В логах нет персональных данных и нет построчного шума.

## Профиль задачи

`hybrid` — 2 сигнала feature (изменение контракта ответа выборки, новые коды состояния) и 2 сигнала bugfix (утечка соединений, молчаливое усечение результата).

## Тир сложности

`standard` — кэш сессий и жизненный цикл клиента GramJS входят в HIGH_RISK_SURFACE.
